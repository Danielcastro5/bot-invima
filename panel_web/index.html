¿Expulsar equipo y cambiar código?

Invalida la clave anterior y genera una nueva limpia

Esta acción realizará lo siguiente de forma inmediata:

  • Expulsará al equipo vinculado (PC-ACTUAL).
  • Destruirá la clave actual (CLAVE). Esa persona ya no podrá ingresar más.
  • Creará una clave nueva de 1 puesto disponible para asignársela a quien desees.
El número total de licencias se mantendrá exactamente igual.

¿Desvincular equipo de la licencia?

Libera el cupo para permitir activar otro equipo

Se liberará la licencia CLAVE del computador PC-ACTUAL.

La clave seguirá siendo la misma, pero quedará disponible para activarse en otro computador.
