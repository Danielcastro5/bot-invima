========================================================================
     SISTEMA DE GESTIÓN DE 20 LICENCIAS INDIVIDUALES (FIREBASE)
========================================================================

Panel de control en tiempo real:
https://console.firebase.google.com/u/0/project/bot-invima-licencias/database/bot-invima-licencias-default-rtdb/data

------------------------------------------------------------------------
1. ¿CÓMO FUNCIONA EL MODELO DE 20 LICENCIAS (1 PUESTO POR LICENCIA)?
------------------------------------------------------------------------
• En lugar de tener 4 licencias compartidas (de 5 computadores cada una),
  ahora cada uno de los 20 puestos de trabajo tiene su propia clave exclusiva.
• Cada clave tiene "max_equipos": 1.
• Cuando un equipo ingresa una clave, su HWID inmutable se vincula a esa clave.
• Si otra persona intenta usar esa misma clave en otro computador, el sistema
  le negará el acceso: "Límite de dispositivos alcanzado (Máximo 1 equipo para esta licencia)".

------------------------------------------------------------------------
2. ¿CÓMO CARGAR LAS 20 LICENCIAS A FIREBASE EN 10 SEGUNDOS?
------------------------------------------------------------------------
Método Rápido por Importación JSON:
1. Abre tu consola de Firebase en la sección "Realtime Database":
   https://console.firebase.google.com/u/0/project/bot-invima-licencias/database/bot-invima-licencias-default-rtdb/data
2. En la parte superior derecha de la base de datos (en la raíz), haz clic en los 3 puntos verticales (⋮).
3. Selecciona "Importar JSON" (Import JSON).
4. Selecciona el archivo "licencias_importar_en_RAIZ.json".
5. ¡Listo! Las 20 licencias quedarán creadas automáticamente dentro del nodo "licencias".

------------------------------------------------------------------------
3. ¿CÓMO GENERAR NUEVAS LICENCIAS O CON OTRO NOMBRE / FECHA?
------------------------------------------------------------------------
Puedes ejecutar desde la consola cuando necesites crear un nuevo paquete:
python generar_licencias.py --cantidad 20 --empresa "Nombre del Cliente" --vencimiento "2026-12-31" --prefijo "INVIMA"

Esto creará automáticamente:
1. "licencias_importar_en_RAIZ.json" -> Listo para importar en Firebase (ignorado por Git).
2. "LISTADO_20_LICENCIAS_CLIENTE.txt" -> Listo para enviar al cliente (ignorado por Git).

------------------------------------------------------------------------
4. ¿CÓMO GESTIONAR, REVOCAR O TRASLADAR UN EQUIPO?
------------------------------------------------------------------------
• TRASLADAR LICENCIA A OTRO COMPUTADOR (si el cliente cambió de PC):
  Entra a Firebase -> busca la clave del cliente -> abre el nodo "equipos" ->
  elimina el HWID antiguo con la (X). En el nuevo computador ya podrán activarla.

• BLOQUEAR O SUSPENDER UN PUESTO ESPECÍFICO:
  Busca la clave en Firebase y cambia "activa" de true a false.
  Ese puesto quedará inhabilitado inmediatamente.
